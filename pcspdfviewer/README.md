## Features

* Open pdfs in tabs
* Search in pdf files

## Technologies

This project was made with:

* Qt version: 6

## Setup

```
$ mkdir -p build
$ cd build
$ qmake ../pcspdfviewer.pro
$ make
$ make install
```
